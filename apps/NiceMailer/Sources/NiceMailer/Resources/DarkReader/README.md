# Dark Reader

`darkreader.js` is the npm package `darkreader` 4.9.134 (MIT License, see
`LICENSE`), unchanged: <https://github.com/darkreader/darkreader>.

The HTML reader runs it in a content world of its own to show a mail made
for a white page in the app's dark theme (`DarkMode.swift`,
`docs/thread-display.md`, "HTML of the sender").

To update it: download the package tarball from the npm registry, check its
`integrity` (SHA-512) against the registry's metadata, copy `darkreader.js`
and `LICENSE` here, update the version above, and run `make test` and
`make ui-test`.
